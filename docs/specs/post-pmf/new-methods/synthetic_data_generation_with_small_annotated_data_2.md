# Residual Learning for Human-Corrected Synthetic Data

## The Idea

LLMs can generate massive amounts of synthetic data, but improving that data with human feedback is expensive. The conventional approach is to collect human-corrected examples and train another model to generate the corrected answers from scratch.

We propose a different approach: **learn to iteratively correct existing outputs**.

Instead of learning the entire mapping from input → ideal answer, we learn the **residual correction** required to improve an existing answer, using a gradient-boosting-style process in a continuous, decodable text latent space.

## Decodable Latent Space

We use **AURORA-LM** as the text encoder-decoder foundation, providing a continuous latent representation that can be decoded back into text.

For an output generated by the original LLM:

```math
z_0 = E(y_0)
```

At each iteration:

```math
y_t = D(z_t)
```

This provides a continuous space in which small modifications to an existing answer can be explored and evaluated through their decoded text.

## Gradient-Boosting-Style Residual Learning

At iteration `t`, the objective is not to predict the ideal answer directly. Instead, the residual model learns the **remaining correction** needed to improve the current output.

Analogous to gradient boosting, it estimates a pseudo-residual corresponding to the direction that decreases the learned human preference loss:

```math
g_t \approx -\nabla_z \mathcal{L}(z_t)
```

The latent representation is then updated incrementally:

```math
z_{t+1} = z_t + \eta g_t
```

where `η` is a **shrinkage factor** that controls the size of each correction.

The process is repeated, progressively improving the same generated answer rather than regenerating it from scratch.

## Learning the Human Loss

We represent human preferences through a parameterized loss over the latent space:

```math
\mathcal{L}(\delta)
=
\sum_i w_i \delta_i^2
+
\sum_{i,j} W_{ij} \delta_i \delta_j
```

Here, `w_i` represents the importance of individual latent dimensions, while `W_ij` captures interactions between latent dimensions.

The loss weights are **not directly predicted by the model**.

Instead, we learn a **weight-learning model** that evaluates perturbations to the loss weights.

For each example, the model receives:

* `h₁`: the first-layer representation of the **original LLM that generated the output**;
* `Δw`: a perturbation to the current loss weights.

It predicts how good that perturbation is:

```math
s = F_\phi(h_1, \Delta w)
```

Thus, `F_φ` learns a differentiable preference landscape over possible changes to the loss weights.

## Human Preference Supervision

At each iteration, only a small subset of generated examples is presented to humans.

For each selected example, we generate small perturbations around the current latent representation:

```math
z' = z_t + \epsilon
```

Each perturbed latent is decoded into text. Humans then rank the resulting outputs, including the current output.

These rankings provide supervision for training `F_φ`.

The weight-learning model therefore learns to predict human-perceived quality from:

```text
Original LLM representation + Loss-weight perturbation
```

rather than directly learning to generate corrected text.

## Discovering the Loss Weights

Once the weight-learning model has learned the local preference landscape, we can use it to discover the appropriate loss weights for a new example.

Starting from the current loss weights, we optimize their perturbation by **gradient ascent through the learned preference model**:

```math
\Delta w^* = \arg\max_{\Delta w} F_\phi(h_1, \Delta w)
```

subject to a fixed perturbation magnitude:

```math
\lVert \Delta w \rVert_2 = c
```

This finds the direction in weight space that the learned model predicts will produce the greatest improvement in human-perceived quality while constraining the size of the change.

The optimized loss weights define the local geometry of human preference for that particular example. This geometry is then used to determine the residual correction in latent space.

## Iterative Correction

The complete process is:

```text
Original LLM
     ↓
Generate Synthetic Output
     ↓
Encode Output into Latent Space
     ↓
Select Small Human-Labeled Subset
     ↓
Generate Local Latent Perturbations
     ↓
Decode Perturbations into Text
     ↓
Human Preference Rankings
     ↓
Train Weight-Learning Model
     ↓
Optimize Loss-Weight Perturbation
     ↓
Infer Latent Residual Direction
     ↓
Apply Shrunk Latent Update
     ↓
Decode Improved Outputs
     ↓
Repeat
```

At every iteration, only a small subset requires new human annotations. The learned correction can then be applied across the much larger synthetic dataset.

As the outputs improve, the next round of human supervision focuses on the **remaining errors**, allowing the system to progressively refine the data.

## Central Hypothesis

**Iteratively learning residual corrections in a decodable latent space can achieve a given level of synthetic-data quality with substantially less human supervision than training a model to generate fully corrected outputs from scratch.**

The key shift is from:

> **"Show the model the entire correct answer."**

to:

> **"Learn which local changes make the existing answer better."**

This turns human feedback into a mechanism for learning a **local preference landscape**, from which the system can discover the appropriate loss geometry and iteratively correct the generated data.
