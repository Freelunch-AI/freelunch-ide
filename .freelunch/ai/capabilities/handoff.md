# Handoff And Pull Request Evidence

Use this capability when updating progress state and preparing `pr` output.

Keep the handoff compact and evidence-based:

- issue and approved scope;
- branch and base branch;
- acceptance criteria status;
- important technical decisions and tradeoffs;
- files or modules materially changed;
- exact validation commands and observed results;
- confirmed review findings and their disposition;
- known limitations, blockers, and remaining work.

Do not paste full source files, secrets, verbose session transcripts, or unverified claims. The progress record is working state; the draft PR description is the durable reviewer-facing summary.
